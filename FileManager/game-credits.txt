Customise the game for your own purposes:
-----------------------------------------------------------------------------
(Even non-developers can modify this game within a few minutes.)

1. You can modify the file "game-strings.json" and translate
the game into your language.
You will find this file in the Program Files folder next to
xInvaders.exe. Feel free to change the hyperlink
to your own website or social media as well.

2. You can also replace the UFO and mine images with your own
pictures. Upload ufo1.png, ufo2.png, ufo3.png, mine1.png,
mine2.png, and deathstar.png into the PNG folder.
Create PNG folder in the same directory where xInvaders.exe
is stored.

Ideal dimensions: UFOs 80x40 (or 80x80) pixels, mines 60x60
pixels, and Death Star 90x90 pixels.

3. You may then zip the files or create an installation file for the
modified game and share it wherever you like.

4. You can add some texts at the beginning of this file,
however do not modify the rest of the game-credits.txt file.
