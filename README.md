![MonoGame](https://img.shields.io/badge/Made%20with-MonoGame-eb3d00?style=for-the-badge&logo=monogame)

## OS
* Windows

## Customize the game for your purposes
* x-Invaders is a simple game that can be customized to match your own style or brand. Even non-developers can modify this game within a few minutes. 
You can change the text shown in the game, replace the enemies with your own graphics, and create your own distribution package. 
More info here: https://www.vt-soft.com/x-invaders/x-invaders-manual
